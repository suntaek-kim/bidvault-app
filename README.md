# 서류금고 (웹 주소용)

조달청·나라장터와 관계없는 민간 서비스입니다.

- 프로그램: https://suntaek-kim.github.io/bidvault-app/
- 체험판(가짜 서류): https://suntaek-kim.github.io/bidvault-app/demo.html
- 현재 버전: v0.6.0

이 저장소에는 완성된 프로그램 화면만 있습니다. 서류는 각 회사 PC의 금고 폴더에만 저장되며 이 주소나 다른 서버로 보내지지 않습니다(프로그램은 외부 연결을 막아 둠: CSP connect-src 'none').
원본 코드와 시험은 비공개 저장소에서 관리하고, 시험을 통과한 배포본만 여기에 올립니다.
